## C. 審閱方法 / How to review

1. 逐節閱讀中文版或英文版（編號一致），在本文件登記問題；<br>Read a section in either language (numbering is identical) and log issues here.
2. 第 4 節每條規則請用真實案例核對：給出輸入（日期、學生數、折扣資格）→ 期望金額，作為「黃金案例」；<br>For Section 4, verify each rule with real cases: input (date, student count, discount eligibility) → expected amount; these become the golden cases.
3. 所有 Open 項決定後，才進入技術選型與實作計畫。<br>Only after all Open items are decided do we proceed to technology selection and an implementation plan.
